# Reproducibility checklist

Before publishing or rerunning the analysis, record:

- [ ] PubMed search query, date, and candidate-gene selection criteria.
- [ ] Species and UniProt mapping table/release.
- [ ] IntAct query, retrieval date, MI score field, and top-five selection rule.
- [ ] STRING organism, 77 input identifiers, confidence score 0.400, evidence channels, FDR setting, and export date.
- [ ] Exact files and filters that yield 125 STRING proteins and 110 Cytoscape nodes.
- [ ] Cytoscape version, topology settings, and yFiles Organic layout.
- [ ] Reactome submitted identifiers, background, correction method, date, and original results export.
- [ ] KEGG organism, release/date, mapping rules, and pathway overlap definition.
- [ ] Source and processing history for every table and figure.

Tool versions mentioned as historical references from June–July 2026 should be verified against actual execution records before being presented as exact versions used.
