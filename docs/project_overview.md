# Project overview

## Objective

Explore Crohn’s disease-associated protein associations and pathway membership using a documented in-silico workflow.

## Workflow summary

Literature search (PubMed) → identifier mapping (UniProt) → interaction selection (IntAct) → association-network expansion (STRING) → graph analysis and visualization (Cytoscape) → pathway enrichment (Reactome) → pathway mapping/overlap (KEGG).

## Scope

This repository is a portfolio and documentation resource for computational validation. It does not report clinical prediction, prove causality, or substitute for experimental validation.
