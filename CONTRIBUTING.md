# Contributing

Documentation corrections, clarity improvements, and methodological suggestions are welcome.

## How to contribute

1. Open an issue describing the proposed correction or suggestion, or submit a pull request.
2. Keep changes specific, factual, and reproducible.
3. Do not invent results, database identifiers, software versions, or parameter values.
4. Distinguish observed outputs from interpretation and hypothesis.
5. Preserve the distinction between STRING output counts and Cytoscape network counts.

## Scope

This repository currently welcomes **documentation-only** pull requests. Please do not add unverified analyses or claim that a proposed change has been validated.

## Reporting an issue

Include the relevant file, the statement that needs correction, and a source or rationale where possible.
