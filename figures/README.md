# Figures

Store publication- or portfolio-ready figures and their editable/source files here.

For each figure, document:

- Figure number and descriptive title.
- Data file(s) used.
- Software and layout or plotting settings.
- Meaning of node colours, shapes, edge styles, and labels.
- Any thresholds used to select or highlight nodes.
- Whether the figure is a network layout, enrichment summary, or pathway mapping.

Network layouts are visual representations, not evidence of physical interaction or causal direction by themselves. Avoid implying directionality unless the source data supports it.
